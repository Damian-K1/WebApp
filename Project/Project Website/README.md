# Portfolio Website

## Project Overview
This project is a personal portfolio website designed to showcase skills, projects, and general information in a clean and organized layout. The site is built entirely using HTML, CSS, and JavaScript, with no external frameworks or libraries.

The primary goal of this project is to showcase my skills in HTML, CSS, and JavaScript. It emphasizes clarity, responsiveness, and ease of navigation.

## Features
- **Responsive Layout**: Designed to work across desktop and mobile devices.
- **Navigation Bar**: Clean and accessible navigation for moving between sections.
- **Project Cards Section**: Projects are displayed using a card-based layout, making it easy to add, remove, or update projects without restructuring the page.
- **Modular Structure**: Organized HTML, CSS, and JavaScript files for readability and maintainability.
- **Custom Styling**: All styling is implemented using native CSS without external dependencies.

## Setup Instructions
Because this is a purely static website, no installation or build process is required.

### Option 1: Open Locally
1. Download or clone the repository.
2. Navigate to the project folder.
3. Open the `index.html` file in any modern web browser.

## Project Structure
```
project-root/
│
├── index.html        # Main entry point
├── styles.css        # Main stylesheet
├── script.js         # JavaScript functionality
├── /assets           # Images and other media
└── README.md         # Project documentation
```

## Adding New Projects
To add a new project to the portfolio:
1. Locate the projects section in `index.html`.
2. Duplicate an existing project card.
3. Update the content (title, description, links, etc.).
4. Save and refresh the browser.

The card-based layout ensures consistent styling and minimal effort when expanding the project list.

## Notes
- No external dependencies are required to run this project.
- All functionality is handled on the client side.
